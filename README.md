# ROSIE

This project, called ROSIE, proposes the Robotics Ontology for Serving Individuals in Everyday tasks (ROSIE). The main goal is to define a knowledge base for the domain of service robots. 

It is important to highlight that the service robots domain is very broad, encompassing concepts and semantics related to the complexity and sophistication of tasks
expected of the robots, as well as the environments and entities/agents with which the robots must interact. To work within a treatable scope, ROSIE has been created, drawing on the RoboCup@Home league as an initial inspiration. The aim is to (a) reduce communication ambiguities, (b) support data integration and information exchange between tools, and (c) allow the construction of computational tools, such as tools for task planning and code generation.
